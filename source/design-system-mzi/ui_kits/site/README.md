# UI kit — site mzi-consulting.com

Recréation de la page d'accueil (site mono-page) composée avec les composants du design system.

- `index.html` : point d'entrée ; bouton en bas à gauche pour basculer en vue mobile 390px.
- `Sections.jsx` : héros, défis, solution, bénéfices, témoignages, méthodologie, pourquoi nous, contact, footer, canvas de fond.

Interactions : ancres de navigation (défilement fluide), menu hamburger mobile, survols, formulaire (état « Envoyé » factice), retour en haut.

Limites :
- Espacement vertical entre sections (≈100px) et largeurs des chiffres-clés : approximés d'après la capture 1440px.
- Témoignages : affichés en grille comme sur la capture (le widget carrousel Swiper présent dans le code n'est pas reproduit).
